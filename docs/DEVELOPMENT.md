# MobileChat

Android 手机端 AI 聊天工具，采用 Kotlin / Jetpack Compose / Miuix 0.9.4，最低 Android 8（API 26）。应用包名 `com.mobilechat.app`，当前版本 `0.1.6`（versionCode 7）。

## 使用

1. 进入「设置 → 添加站点」，填写站点名称、完整 Responses 接口地址及 API Key。
2. 地址示例：`https://example.com/v1/responses`。应用直接请求填写的地址，不会追加 `/v1` 或 `/responses`。API Key 留空时不发送 Authorization。
3. 模型名称每行一个；点击模型标签选择默认模型。初始列表为 `gpt-6.1-sol`、`gpt-5.6-sol`，名称是否可用由站点决定。
4. 系统提示词、最大输出 token 数、推理强度均可不设置。未设置的字段不发送。
5. 点击「测试连接」检查当前配置，保存后新建会话。会话顶部可以切换站点或模型，生成期间禁止切换。
6. 通过输入栏的加号选择图片、调用系统相机拍照或选择任意格式的文件，再点击发送。回复支持 Markdown、表格、代码块及复制。
7. 输入 `/model` 打开模型选择，或用 `/model 模型名称` 直接切换当前会话的模型；输入 `/effort` 选择推理强度，或用 `/effort high` 直接设置。支持 `none`、`minimal`、`low`、`medium`、`high`、`xhigh`，`/effort default` 恢复跟随站点默认值，`/help` 查看帮助。命令不进入聊天历史、不发送到服务端，并保留待发送附件；生成期间禁止切换。
8. 站点默认开启「思考进展」，请求服务返回思考摘要。实际返回的思考摘要或进展在回答上方以灰色小字展示，可以展开或收起，并随会话保存。服务未返回时只显示等待状态；不解密或展示加密的推理内容。若站点或模型不支持摘要请求，可在站点配置中关闭此选项。
9. 新回答采用渐显与轻微弹簧入场，新收到的文字由浅入深并轻微回弹；历史回答不重复播放，系统关闭动画时遵循系统设置。

站点提示 `unauthorized client detected` 时，在该站点的「连接信息」中开启「Codex 兼容」，再保存配置。该选项按站点保存，已有站点默认关闭；连接检查与聊天使用同一套兼容请求。

兼容模式参照公开的 Codex CLI `rust-v0.98.0` HTTP 请求，发送 `codex_cli_rs` 的 User-Agent / originator、会话 `session_id` 及对应 Responses 字段。完整接口地址与 Bearer Key 仍使用填写的值；不发送 `max_output_tokens`，保留模型、历史、系统提示词与推理强度。客户端权限仍由中转站决定，当前尚未验证截图中的真实站点。

HTTP 地址用于本地或特殊中转站，会以明文连接。手机上的 `127.0.0.1` 指手机本身；连接电脑的中转站应使用手机能够访问的电脑局域网地址。

## 行为与数据

- 请求使用 Responses 的 `model`、`input`、`stream: true`、`store: false`，不依赖服务端保存的 response ID。非空 Key 使用 Bearer 认证。
- 首页、聊天、设置和站点编辑之间使用滑动与淡入淡出动画。Android 14+ 的预测性返回按手势进度预览上一页，支持左右边缘和取消回弹；较旧 Android 的返回键使用普通切换动画。首页返回交给系统处理。
- 返回预览不提交导航或清空会话；编辑字段和列表位置通过页面状态保存，手势完成后才弹出页面。
- 会话与配置保存在本机，每次发送包含当前会话的历史及其附件。切换站点后，历史也发送至新选择的站点。
- 文件选择不限制扩展名或 MIME 类型。JPEG / PNG / WebP 使用图片输入；1 MB 以内且可解码的 TXT / Markdown 使用文本输入（UTF-8、带 BOM 的 UTF-16、中文 GB18030）；其他格式、较大文本或不能解码的文本使用内联 `input_file`，保留完整文件内容与文件名。
- 单个附件及完整请求含历史的附件原始总大小须小于 50 MB。附件 Base64 从磁盘流式写入，不静默截断；服务能否解析所选文件由中转站及模型决定。
- 拍照调用系统相机，以 FileProvider 临时授权保存原尺寸 JPEG；拍摄完成后导入附件，取消拍摄或完成导入后清理临时照片。
- 文件输入仅使用配置的 Responses 接口，不要求额外 Files API。
- 停止、断流及进程退出后保留已保存的部分回复；请求不自动重试。
- 重新生成先保存临时回复，成功后替换原回复；失败时原回复保留。可以重试最后一条助手回复。
- Room 保存会话、消息、附件元数据；DataStore 保存站点和外观；Key 使用 Android Keystore AES-GCM 加密。系统备份关闭，网络请求和密钥不写入日志。
- 数据库 v1 → v2 为现有表追加会话推理强度及回复思考内容字段，不清空旧会话、附件或站点配置。
- 玻璃默认关闭，开启后只应用到聊天顶部与输入栏。API 33+ 且硬件加速时使用 Miuix 背景模糊，其余设备使用实色。

## 开发与验证

工具链：JDK 21、Gradle 9.5.0、AGP 9.3.2、Kotlin Compose / Serialization 插件 2.4.0、Android SDK 37。将 SDK 路径写入本机 `local.properties`，该文件不应提交。

以下命令编译源码、运行 JVM 测试及 Lint，**不生成 APK**：

```powershell
.\gradlew.bat :app:compileDebugKotlin :app:testDebugUnitTest :app:lintDebug :app:compileDebugAndroidTestKotlin
```

依赖下载需要代理时，可以附加本机配置：

```powershell
'-Dhttp.proxyHost=127.0.0.1' '-Dhttp.proxyPort=7890' '-Dhttps.proxyHost=127.0.0.1' '-Dhttps.proxyPort=7890'
```

## APK 打包

用户要求后续默认提供开启 / 关闭 R8 的两个版本。运行：

```powershell
.\scripts\package.ps1 -Offline
```

默认 `-Variant both` 同时生成 `release`（R8 开启）和 `releaseNoR8`（R8 关闭），复制到 `dist/` 并核对签名、SHA-256 和非调试标记。需要下载依赖时去掉 `-Offline`，可加 `-Proxy http://127.0.0.1:7890`。

- R8 开启：`MobileChat-0.1.6-r8-on.apk`，启用优化、代码缩减 / 混淆及资源缩减。
- R8 关闭：`MobileChat-0.1.6-r8-off.apk`，不启用代码及资源缩减。
- 两个版本均为非调试构建，使用相同包名、版本和已有 Android Debug 证书，可覆盖安装及互换；聊天数据和配置无需卸载清除。
- APK 旁边生成 `.sha256` 文件，`dist/package-report.json` 记录版本、R8 状态、签名证书和文件校验值。
- 设置页显示版本及 R8 状态，便于确认当前安装的是哪一个。

仅生成一类可使用 `-Variant r8` 或 `-Variant noR8`。旧版 `dist/MobileChat-0.1.0-debug.apk` 作为历史产物保留，不能代替新的非调试 R8 关闭版进行对比。

目前尚未连接 Android 设备或实测真实中转站，打包成功不代表已验证实际帧率或优化后的运行行为。
